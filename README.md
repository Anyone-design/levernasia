# Levernasia Lounge & Bar Website

A luxury, high-energy, responsive multi-page business website built for **Levernasia Lounge & Bar** located at **Gardens Galleria Mall, Sector 38A, Noida**, utilizing React, Vite, Tailwind CSS, and Lucide React.

## 🚀 Features

- **Multi-Page Architecture:**
  - **Home (`/`)**: Luxury hero banner, real-time operating status, 4 pillars of hospitality, signature chef & mixology dishes, Google Reviews carousel, and location map preview.
  - **About Us (`/about`)**: Brand story (LA glamour to Noida), 3 core values, filterable experience photo gallery with lightbox, and culinary/mixology team profiles.
  - **Menu & Experiences (`/services`)**: Filterable categorized menu, live search by name/ingredient, dietary filters (*Veg, Non-Veg, Chef Specials*), item detail modals with flavor profiles, and VIP cabana celebration packages.
  - **Contact & Location (`/contact`)**: Interactive inquiry & reservation form with live validation, full Google Map embed, weekly hours schedule with today's automated highlight, directions guide, and guest FAQs.
- **Interactive Reservation Modal:** Instant table booking with date/time picker, seating zone selection, party size, and celebration confetti.
- **Mobile-First & Fully Responsive:** Clean mobile drawer navigation, sticky navbar, and floating quick-booking widget.

---

## 🛠️ Tech Stack

- **Framework:** React 18 with Vite
- **Styling:** Tailwind CSS (Custom Dark Noir & Champagne Gold Luxury Theme)
- **Icons:** Lucide React
- **Animations & Effects:** Canvas Confetti, Tailwind Animations
- **Routing:** React Router DOM (v6)

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Anyone-design/levernasia.git

# Navigate into the project folder
cd levernasia

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Production Build
```bash
# Build the production bundle
npm run build

# Preview the production build
npm run preview
```
